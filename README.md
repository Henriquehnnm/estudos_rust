## Como rodar os projetos

1. Clone o repositório:
```bash
git clone https://github.com/SEU_USUARIO/NOME_DO_REPO.git
```

2. Entre na pasta do projeto desejado:
```bash
cd NOME_DO_PROJETO
```

3. Compile e rode o projeto:
```bash
cargo run
```
